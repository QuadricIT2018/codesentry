# 🚀 SlopTask AI — Artificial Productivity

**One checkbox. Infinite abstractions. Zero reasons to ship.**

SlopTask AI is a lovingly overengineered to-do app concept: agent swarms, vibes-based productivity metrics, faux quantum prioritization, and a dashboard that treats checking a box like a moon landing.

## Features

- Functional task creation, completion, deletion, search, and filtering
- Responsive dark-mode dashboard with purple gradients and glassy panels
- Simulated AI agent orchestration, productivity insights, and focus actions
- Intentionally absurd product language and metrics
- No API key, backend, account, or external AI service required

> **Important:** The AI output and analytics are simulated UI behavior, not real model inference or measured productivity data.

## Run locally

Requirements: Node.js 20+ and npm.

```bash
npm install
npm run dev
```

Open the local URL printed by Vite. For a production build:

```bash
npm run build
npm run preview
```

## Stack

- React + Vite
- Plain CSS with responsive layouts
- Lucide icons
- In-memory state (refreshing the page resets demo tasks)
